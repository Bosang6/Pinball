# Pinball

A retro realistic-style 3D pinball game developed with **Unreal Engine 5**.

This project is a small pinball game prototype focused on physics-based gameplay, interactive table elements, UI, sound effects, and basic game state management.

## Features

- Physics-based pinball gameplay
- Player-controlled flippers
- Ball launcher
- Score and coin UI
- Start screen and camera sequence
- Sound effects

## Controls

| Key   | Action           |
| ----- | ---------------- |
| Enter | Start game       |
| Q / P | Control flippers |
| I     | Insert coins     |
| L     | Load ball        |
| Space | Launch ball      |
| Esc   | Quit game        |
